# javascript-calculator-precourse

## 기능 구현

- [x] 사용자 입력 받기
  - [x] '덧셈할 문자열을 입력해주세요' 출력
- [x] 입력 받은 문자열 커스텀 구분자 확인
  - [x] "//" 와 "\n" 사이 구분자 있다면 추출
  - [x] 커스텀 구분자 없다면 기본 구분자 사용
- [x] 커스텀 or 기본 구분자로 문자열 분리
- [x] 문자열을 숫자 배열로 파싱
- [x] 파싱한 숫자들을 계산
- [x] 결과 출력

## 예외 처리

- [x] 구분자 사이에 숫자가 아닌 값이 포함된 경우
- [x] 음수가 포함된 경우
- [x] 커스텀 구분자 형식이 옯바르지 않은 경우 (예: "//"만 있고 "\n" 없는 경우)
- [x] 연속된 구분자가 사용된 경우 (예: 1,,2;3)
